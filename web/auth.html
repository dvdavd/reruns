Forgot your password?

Ask an admin to set a new one for you from Settings > Accounts.

If you are the admin, run this where the server runs:

reruns --reset-password username

With Docker, run it in the container as the server's user (PUID, 1000 by default):

docker compose exec --user 1000 reruns reruns --config /config --reset-password username
