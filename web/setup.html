How will people sign in?

You can switch later, but accounts made under one way do not carry over to the others.

Single sign-on (OIDC)

Reruns reads its provider from the server's settings, so this is set up outside the page.

  1. In your provider, make a client and register this redirect address:
  2. Give the server these settings, with your own values: Optionally:
  3. Restart the server and come back here. Members of the admin group become admins the first time they sign in.

Members of the admin group become admins. The libraries claim lists the libraries a new account can see, by folder name, or * for all; without it, they see every library.

No sign-in

Sign-in is switched off when the server starts, so this is set up outside the page.

  1. Start the server with sign-in turned off: RERUNS_NO_AUTH=true or pass {child} on the command line.--no-auth
  2. Restart it, and the library opens straight away.

Keep the server on 127.0.0.1, or behind something that checks who is asking.
